[2026-09-22] - 徹底消除 `<br>` 標籤外露與表格排版擠壓重構 (Purge `<br>` Tags & Anti-Table Layout Overhaul)
- 問題分析：
  * 使用者反應「又出現 `<br>` 了，而且排版看著很不方便」。
  * 根源定位：
    - 當查詢 Portal 報帳流程或會計規章時，模型嘗試將多步驟的操作重點塞入單一 Markdown 表格單元格中，並在單元格內強行插入 `<br>` 作為換行符號。
    - 前端 Markdown 渲染器未解析 `<br>` 標籤，導致 `<br>` 原字外露；且長文字塞入表格造成寬度暴增，手機或窄螢幕產生橫向滾動條，左側欄位被嚴重壓縮至僅剩 4 個字（如「會計系統」），右側文字擠壓成團，閱讀極不方便。
- 調整與修正：
  * **【排版重構：長文字與操作流程全面禁用 Markdown 表格】**：
    - 重構 `query_accounting_rules`，為 Portal 報帳與採購單建立流程（`is_portal_flow`）及全域報帳核心規範（`is_general`）提供專屬的純文字結構化 `formatted_response`。
    - 捨棄任何 Markdown 表格包裝，一律改採 Markdown 三級標題（`### 📌`）搭配項目符號（`*`）與流程箭頭（`➔`）垂直展開。
    - 各裝置（手機、平板、窄版對話框）自動折行適配，徹底杜絕橫向滾動條與文字擠壓問題。
  * **【全域輸出 HTML 標籤過濾清洗機制】**：
    - 在 `openclaw_setup/irl_agent.py` 實作 `_clean_html_tags` 與 `safe_output`，在命令列輸出前全域過濾 `<br>`、`<br/>`（自動替換為換行 `\n`）與所有 HTML 標籤（`<b>`、`<div>`、`<span>` 等），作為底層雙重防呆保證。
  * **【強化 AGENTS.md 指引規範】**：
    - 明確下達【排版鐵律：長文字與多步驟絕對禁止使用 Markdown 表格】，表格僅限純短數據（金額流水帳、設備編號），操作流程一律垂直清單展開。
    - 嚴格重申禁止輸出任何 HTML 標籤與阿拉伯數字開頭編號。
- 驗證：
  * 實測 `openclaw_setup/irl_agent.py query rules portal` 與 `query rules 報帳規定`，100% 回傳乾淨垂直 Markdown，零 `<br>`，排版極為清爽舒適。
